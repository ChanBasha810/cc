# Birthday Moments — React

A cinematic, responsive birthday website built with React, Vite and Motion for React.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Customize

Open `src/main.jsx` and change:

- `NAME`
- `memories` image URLs, titles and captions
- the birthday message
- audio URL if desired

The design uses remote images so the project works immediately without adding image files.

## Build

```bash
npm run build
npm run preview
```

Motion for React is used for entrance, hover, tap, lightbox and gift animations.
